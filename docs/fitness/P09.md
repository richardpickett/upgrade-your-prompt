# P09 — The first statement of a new fact

Rung 5 practice.

A fact that was not in the store and not in an earlier turn is said once. That is not repetition. It is the necessary first utterance. Saying it a second time, unchanged, is a different and worse indicator.

Say the new fact in the turn that needs it. If it will still be true next time, write it into the store before the session ends so the next prompt can point instead of tell.
