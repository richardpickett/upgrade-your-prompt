# F17 — The prompt is the patch

Rung 8 failure. Holds the session at 7.

You paste the corrected line, command, or config yourself. The agent becomes a typist. The system does not learn the miss, because the fix never passed through a record or a regenerated result. Next time the same miss is available again.

Say the failing check and tell the agent to rebuild from the corrected record. If you already pasted the patch, write the reason into the store before you move on, or this save will not stick.
