# P03 — One outcome is in force

Rung 3 practice.

When more than one finished condition is in play, the prompt says which one this turn is, or the order they happen in. The agent is not left to merge them into a single invented task. Split work stays split.

If you notice two outcomes, label them and say which is now. Finish or explicitly drop one before starting the other. Do not rely on the agent to guess the priority.
