# F14 — A citation misses the record

Rung 5 failure. Holds the session at 4.

The prompt names a decision, rule, or file, and the text that was read does not contain that decision. The pointer feels efficient and sends the agent to the wrong law. Later work inherits the miss with high confidence.

Open the record you named. Either cite the decision that is actually there, or write the decision you thought was there and cite that. Do not leave a name that the file does not back.
