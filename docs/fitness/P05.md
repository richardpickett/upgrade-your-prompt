# P05 — The example agrees with the rule

Rung 3 practice.

An example you supply would pass the instruction it sits under. The agent can imitate it without breaking the rule. Examples are how a lossy sentence becomes a concrete case, so the case has to be a legal one.

Read the example against the rule before you send it. If the example is the exception, say it is the exception and what makes it one. Otherwise change the example, not the agent's reading.
