# P11 — The procedure is invoked, not pasted

Rung 6 practice.

You name the skill or the command. You do not paste its steps. A tool then runs that command. The procedure stays in one place, so the prompt cannot drift from the current steps.

Name it and let the tool run. If you do not trust the command, fix the command. Pasting today's steps means the next change to the procedure will not reach this prompt.
