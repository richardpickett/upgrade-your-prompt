# F02 — A check that cannot fail

Rung 2 failure. Holds the session at 1.

Done is "looks good", "make sure it's right", or the agent's own summary of its work. Nothing in the prompt can be false, so a pass is a mood. The result can miss the outcome and still be called finished.

Replace the mood with a condition that could fail. If you already have an end state, ask what evidence would prove it is not met, and require that evidence before you accept.
