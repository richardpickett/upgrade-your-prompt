# P04 — The deciding fact is present before the agent acts

Rung 3 practice.

The fact that would change the result is in the prompt, or already in a record the agent read, before the first attempt. You do not wait for a miss to reveal the constraint, the path, or the exception. The attempt is aimed at the real outcome.

Before you let the agent write, ask what fact would make this attempt wrong. If you know it, say it now. If it lives in a decision or a file, point at that record instead of hoping the agent infers it.
