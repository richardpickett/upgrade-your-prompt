# P13 — The check is a command that a tool runs

Rung 7 practice.

The done check is a command or test already in the repo, and a tool runs it. The output is the evidence. A prose description of success is not required once the command exists, and it is weaker when the two disagree.

Name the command in the prompt. Read the tool result before you accept. If no command exists for this outcome, add one and store it, so the next session can point at it.
