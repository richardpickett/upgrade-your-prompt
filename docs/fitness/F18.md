# F18 — The human says they already fixed it

Rung 8 failure. Holds the session at 7.

A later turn says you fixed the result, and no earlier turn stated that change as the outcome. The product moved outside the agent. The store did not see the correction, so fidelity does not rise.

Tell the agent what you changed and have it write that fact or rule down. Then have it regenerate or re-check from that record. A private fix is a one-time save with no next session.
