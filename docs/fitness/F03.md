# F03 — Two outcomes treated as one

Rung 3 failure. Holds the session at 2.

The prompt contains two finished conditions and never says which this turn is. The agent picks one, blends them, or builds a third thing that matches a reading you did not mean. The later correction is usually "that wasn't the ask."

In the next turn, name both outcomes and mark one as now and the other as later or dropped. Do not repeat the whole brief. The split is the entire correction.
