# F20 — The miss stays in the chat

Rung 8 failure. Holds the session at 7.

A new decision or fact is created in the conversation and never written. The chat is not a store the next session loads. The next time you work that domain you ask the same questions again, because nothing durable held the conclusion. ADRs, goals, and a knowledge domain are that store. Asking is the right way to reach the conclusion. Asking it again from scratch is this failure.

Before you end the session, write the decision down. If it is not worth storing, it was not a standing fact: do not expect the next prompt to be shorter.
