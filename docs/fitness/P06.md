# P06 — The path leaves the goal intact

Rung 3 practice.

When you name steps, those steps can still reach the finished condition. The steps are a way to get there, not a replacement for saying where there is. The agent can follow the path and land on the outcome.

State the end state first. Add steps only where the path is a real constraint. If a step would make the outcome impossible, drop the step or change the outcome in the same turn.
