# P08 — Unchanged policy is read, not pasted

Rung 5 practice.

Rules and facts that already sit in a decision, a standing instruction, or another record are pointed at. The agent reads them. The prompt does not include their text. Your new words are the change. The first time a fact is true, saying it once still belongs here.

Point at the record by path or name, and have the agent read it before acting. If you feel the need to paste, the pointer is not reliable: fix the pointer, or say this is the first statement of that fact and then store it.
