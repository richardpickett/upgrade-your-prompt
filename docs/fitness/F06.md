# F06 — The path replaces the goal

Rung 3 failure. Holds the session at 2.

The prompt is a list of steps, and the finished condition is missing or the steps cannot reach it. The agent completes the list and stops. You then discover the goal was never in the prompt.

Write the finished condition in one sentence. Keep a step only if it is required for that condition. If the steps and the goal cannot both be true, say which one wins.
