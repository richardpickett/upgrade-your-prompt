# P01 — The end state is named

Rung 1 practice.

Say what finished looks like, in one prompt or across the series. A person rarely knows the whole scope on the first turn. "List the gaps I would leave off" and "what is the best way to judge a small sample" are part of the goal. They count as practice, not as a missing end state.

"Fix the bug" with no finish and no question aimed at one is still only an activity. "The critique's only score is the rung" is a finished condition. So is a run of questions that arrives at that sentence.

The miss is not the question. The miss is reaching a conclusion and leaving it in the chat, so the next session about the same domain has to ask it again. That is F20, not F01.
