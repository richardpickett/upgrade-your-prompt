# P18 — The writer and the checker are different passes

Rung 8 practice.

The pass that produces the artifact is not the pass that declares it proved. A second command, skill, or review reads the result. The author does not audit its own story. Deterministic output can be checked with high fidelity when the checker is not the writer.

Ask for the check as a separate step after the write. Do not accept "I verified" from the same pass that just wrote the file. If the checker is a command, run the command.
