# P12 — A bound fact is not re-answered

Rung 6 practice.

The agent asks for a goal, rule, or fact that a tool result already contains. You point at that record instead of answering in prose. The store stays the source. Your reply does not become a second copy.

Answer with the path or the id. If the agent asked because the record is unclear, fix the record. Do not fill the chat with a restatement the file should have carried.
