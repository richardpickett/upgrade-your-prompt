# P10 — The opening turn is a pointer

Rung 6 practice.

The first thing you say is a continuation, a skill name, or an id. The agent then reads the packet, the decisions, or the rules before any new policy is spoken. The session starts from what is already bound. You do not re-teach the system in the opening turn.

Start with the pointer and stop. Let the read happen. Add a new fact only after that read, and only if the store does not already contain it.
