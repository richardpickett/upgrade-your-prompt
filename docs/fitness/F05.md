# F05 — The example fights the rule

Rung 3 failure. Holds the session at 2.

The example would fail the instruction above it. The agent has two meanings and will often follow the example, because an example is easier to copy than a rule. The result then looks faithful and is still wrong.

Delete the example or change it so it would pass. If both meanings are real, they are two outcomes: split them. Do not leave the contradiction for the agent to reconcile.
