# P02 — The check can fail

Rung 2 practice.

A real check can come back false. "The tests pass", "the file contains the rung and no area score", or "the command exits 0" can fail. "Make sure it looks good" cannot. A check that can fail is how you and the agent share one meaning of done.

Put the check in the same turn as the end state. Prefer a command, a file fact, or a sentence with a yes/no. If the only check is taste, name the observable stand-in you will actually accept.
