# P19 — The new record is obeyed

Rung 9 practice.

After a decision or rule is written, a later tool reads it, and no human turn between those two events restates it. The new record is doing the work. You did not have to say it again for it to take effect.

Write the record, then have the next step read that path. If you feel you must repeat it, the read did not happen or the record is unclear. Fix that, instead of adding another copy in the chat.
