# F13 — The human repeats an unchanged fact

Rung 5 failure. Holds the session at 4.

The same fact, rule, or goal appears again in a later turn and nothing about it changed. The second copy teaches the agent that the store, or the first turn, cannot be trusted. Speech went up for no new outcome.

Cut the repeated sentence. If the agent ignored the first statement, point at it or at the record. If the fact changed, say only what changed.
