# F09 — The goal moves and the old one is not dropped

Rung 4 failure. Holds the session at 3.

A later turn wants a different finished condition and never says the first one is cancelled. Both stay in force. The agent either chases the new one while the old files remain, or tries to satisfy both.

Say the old outcome is dropped, then say the new one. If both still matter, order them. Do not let a new sentence silently replace an old one.
