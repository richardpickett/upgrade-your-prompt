# P07 — The outcome lands

Rung 4 practice.

The result that remains is the one you named. You accept it, or the check you stated is met. Work that was rejected and then repaired counts only when the repaired result is the one that stays. A cheaper wrong result does not.

When the result is in front of you, compare it to the finished condition and the check, not to the effort. Accept only that match. If it does not match, reject it in the next turn by naming the miss.
