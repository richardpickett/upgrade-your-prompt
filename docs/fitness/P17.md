# P17 — The miss or new fact is written to the store

Rung 8 practice.

A decision, rule, or fact created by this miss is written into the store, not left only in the chat. The next session can read it. This is how a one-time correction becomes less speech later, including for a new application that uses the same system.

Have the agent write the record in the same session as the miss. The record should say what was wrong and what replaces it. The old wording stays marked as replaced so the miss is not re-learned.
