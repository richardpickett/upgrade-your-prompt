# F12 — The store is pasted as well as named

Rung 5 failure. Holds the session at 4.

The prompt names a record and also includes the record's text. The pointer did no work. You paid the full speech cost, and the pasted copy can drift from the record the next time the record changes.

Delete the pasted body. Keep the name or path, and have the agent read it. If the paste differs from the record, one of them is wrong: fix the record, do not keep both.
