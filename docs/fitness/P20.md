# P20 — The non-goal arrives before the extra build

Rung 9 practice.

You say what not to build before tools write the adjacent thing, and those paths are not written. The agent does not spend the turn on the neighboring product and then get told to undo it. The boundary of the outcome is part of the first instruction.

Name the adjacent work you do not want in the same turn as the outcome, or rely on a stored non-goal the agent reads. If the extra files already exist, the next turn is to remove them and store the non-goal so the next run does not recreate them.
